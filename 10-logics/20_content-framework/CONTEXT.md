# 20_content-framework — the seven categories

One job: define what UnitEd teaches. Every resource in the library maps to
exactly one of these categories (or `none`).

| File | Holds |
|---|---|
| `00_overview.md` | how the framework was derived + the category list |
| `01_relevance-matrix.md` | priority, relevance, variance, design consequence per category |
| `1-1_teaching-learning-fundamentals.md` | 1.1 Teaching & Learning Fundamentals |
| `1-2_teacher-presence-communication.md` | 1.2 Teacher Presence & Communication |
| `1-3_classroom-management.md` | 1.3 Classroom Management |
| `2-1_inclusive-teaching.md` | 2.1 Inclusive Teaching |
| `2-2_context-responsive-teaching.md` | 2.2 Context-Responsive Teaching |
| `3-1_ethics-safeguarding.md` | 3.1 Ethics & Safeguarding |
| `3-2_teacher-growth-wellbeing.md` | 3.2 Teacher Growth & Wellbeing |
| `99_keywords.md` | bundled research/search keywords per category |

All body text is final research, adopted verbatim from *Training Topic
Research_V2*. Categories are referenced as `1.1` … `3.2` in
frontmatter across the repo — renaming one means updating every reference in
the same change.
