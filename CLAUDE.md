# UnitEd Resources

The curated knowledge base behind UnitEd workspaces: the logics that decide
what a teacher learns next, and the resource library those steps are drawn
from. Read live by the UnitEd web app; edited by humans and agents.

Built on ICM: folders carry sequencing, hierarchy carries context, files
carry state. The structure is the documentation — every folder explains
itself in its own `CONTEXT.md`.

## Where things live

| Folder | What it holds |
|---|---|
| `00-inbox/` | uncategorized drops — everything new lands here first |
| `10-logics/` | the logics: who learners are, the content framework, how matching works |
| `20-resources/` | the library: native resources, third-party links, big providers |
| `_templates/` | blank starters — new content is a copy, never a blank page |

## Route by task

| If | Go to |
|---|---|
| adding a native resource | `20-resources/10_native/CONTEXT.md` |
| adding an external link | `20-resources/20_links/CONTEXT.md` |
| adding a big provider | `20-resources/30_providers/CONTEXT.md` |
| triaging what landed in the inbox | `00-inbox/CONTEXT.md` |
| changing who we teach or what we teach | `10-logics/CONTEXT.md` |
| changing how a profile picks the next step | `10-logics/30_matching/CONTEXT.md` |
| wiring the app to this repo | `CONTEXT.md` here at root — the query protocol |

## The one rule

Text in `10-logics/10_learners/` and `10-logics/20_content-framework/` is
final research: categorize it, link it, never rewrite it.
